| 项 | 值 | 怎么拿到的 |

**SELinux 是 Permissive 这件事很关键**：普通 `shell` 用户都能 `setprop persist.*`，不用 root。

## 开 ADB

创维的 ADB 开关藏得比较深，一般在：

```
设置 → 关于 → 连续按"版本号" → 开发者选项 → USB 调试 / 网络调试
```

这台机器出厂就开着 5555，`adb connect <TV_IP>:5555` 直接连上。

## 第一件事：备份

改动前先把状态存下来，后面每一步都能对照、能回滚：

```powershell
$bk = "backup-$(Get-Date -Format yyyyMMdd)"
New-Item -ItemType Directory -Force $bk
adb shell pm list packages            > "$bk/packages-all.txt"
adb shell pm list packages -d         > "$bk/packages-disabled.txt"
adb shell getprop                     > "$bk/getprop.txt"
adb shell settings list global        > "$bk/settings-global.txt"
adb shell settings list secure        > "$bk/settings-secure.txt"
adb shell settings list system        > "$bk/settings-system.txt"
adb shell "cmd package query-activities -a android.intent.action.MAIN -c android.intent.category.HOME" > "$bk/home-activities.txt"
```

备份的意义在实战里体现过：改造到一半发现某个按钮没了，靠 `packages-disabled.txt` 一眼看出少了哪个包。
